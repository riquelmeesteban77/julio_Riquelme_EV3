# Aplicación Web en Flask - Menú y Ejercicios

Proyecto académico desarrollado en **Python** utilizando el microframework **Flask**, que implementa un menú principal de navegación y dos módulos de ejercicios prácticos con estilos CSS externos.

## 🚀 Tecnologías Utilizadas
* **Python** (Lenguaje principal)
* **Flask** (Framework web)
* **HTML5 / CSS3** (Estructura y diseño modular)
* **Jinja2** (Motor de plantillas)

## 📂 Estructura del Proyecto
```text
mi-proyecto-flask/
│
├── main.py                 # Archivo principal que ejecuta la aplicación Flask
├── static/                 
│   ├── css/                # Hojas de estilo externas
│   │   ├── stylesejercicio1.css
│   │   └── stylesejercicio2.css
│   └── img/                # Imágenes y recursos gráficos
│       ├── imagen1.png
│       └── imagen2.png
└── templates/              # Plantillas HTML
    ├── index.html          # Menú principal con botones de navegación
    ├── ejercicio1.html     # Vista del Ejercicio 1
    └── ejercicio2.html     # Vista del Ejercicio 2
